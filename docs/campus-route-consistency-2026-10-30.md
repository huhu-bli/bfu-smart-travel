# 校园路线学校与数据来源一致性修复

北交 Agent 路线进入手动规划器后，重新生成曾固定使用北林数据；数据库校园路线的页面编辑也曾退回校园注册表的静态副本。这次把手动设置绑定到当前计划，并按计划的 spotSource 重新查询同一学校的资料。

数据库计划增删、重新生成、门岗和点位详情共用数据库候选。新增点位与最新停留时间继续参与计算；已归档的选中点位可在编辑器取消。查询失败或保留点位失效时原计划保持不变。明确为静态来源的初始离线导览仍可离线编辑。旧缓存未标来源时按数据库读取。

校园与城市编辑复用同一更新锁，Agent 替换计划后旧查询不能覆盖新计划。手动时长从当前计划初始化，75 分钟等非预设值不会被取整到最近档位。

1. 通过 Agent 生成北交校园路线，查看手动入口标题与门岗。修改时长后重新生成，确认学校、起点及点位仍属于北交。

3. 在测试数据库归档一个已选点位，确认编辑器可以取消它，保留失效点位时应报错而非用旧数据补回。
4. 模拟景点接口失败，重新生成或编辑应保留旧计划并显示错误；在明确的静态离线计划中断网，编辑仍应可用。
