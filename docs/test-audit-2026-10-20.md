## 剩余风险与后续优先级

1. **公开代理的额度防滥用仍较弱。**可信 Origin 是浏览器跨域策略，不是用户身份认证；非浏览器客户端可以填写 Origin。现有限流存于进程内，不能保证多个 Serverless 实例共享总额度。公开推广前应增加共享存储限流或平台 WAF，并设置供应商费用上限。本次没有新增基础设施或改变免登录产品流程。
2. **异步编辑缺少处理中反馈。**获取数据库候选期间仍显示旧计划，网络较慢时用户可能重复点击。当前版本用 revision 避免旧结果覆盖新结果，但这不等于能合并同时发生的多次编辑。下一步应增加明确的更新中状态或串行编辑机制。
3. **跨区编辑能力仍有限。**编辑器目前按路线的行政区读取候选，不能在任意一条单区路线里直接浏览全北京地点。需要增加搜索/地区切换，并明确扩大路线范围。
4. **本地保存数据缺少完整结构验证。**JSON 解析失败有兜底，但合法 JSON 且结构不符的旧缓存仍可能导致渲染错误。应为全局计划和聊天历史增加版本化校验与恢复。
5. **手机真机待验收。**已检查移动端样式、滚动锁定实现及桌面行为；未在真实 iOS / Android 或中国移动网络上完成测试。不能据此保证所有手机和网络均可访问 Vercel。
