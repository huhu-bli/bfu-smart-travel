# 海淀综合旅行地图

## 目标

在保留北京林业大学校园 SVG 地图和校园路线算法的前提下，将地图浏览范围扩展到整个海淀区。综合地图用于发现校外旅行点位，不改变现有校园路线的数据和计算逻辑。

## 当前图层

| 图层 | 运行时检索关键词 | 用途 |
| --- | --- | --- |
| 景点 | 旅游景点 | 风景名胜与热门去处 |
| 公园 | 公园 | 城市公园与自然空间 |
| 文博展馆 | 博物馆 | 博物馆、纪念馆与展馆 |
| 高校 | 高等院校 | 海淀高校与校园位置 |
| 餐饮 | 特色餐厅 | 旅行途中用餐发现 |
| 地铁交通 | 地铁站 | 到达与换乘参考 |

每类最多查询 50 条，兼顾海淀覆盖范围和手机端渲染性能。结果会按照行政区或地址过滤为海淀区，并按 POI 标识去重。

## 代码结构

```text
src/data/haidianPlaces.ts    POI 分类、文案与检索任务
src/lib/amapLoader.ts        高德 JS API 加载与类型边界
src/components/HaidianMap.tsx 地图、分类、搜索、选择与外部查看
src/styles/haidian.css       综合地图响应式样式
```

`App.tsx` 只负责在“北林校园路线”和“海淀综合地图”之间切换。`src/data/spots.ts` 仍只保存校内景点，因此海淀 POI 不会污染校园路线算法或 Agent 的校内上下文。

## 数据边界

综合地图使用高德地图运行时 POI 检索，而不是把大量地点写死进仓库。这样可以减少过期数据，但地图结果不等同于旅游或政府部门的正式名录。开放时间、票价和营业状态应以场所官方通知为准。

## 部署配置

1. 在高德开放平台创建“Web 端（JS API）”应用和 Key。
2. 把 GitHub Pages 域名加入高德安全域名白名单。
3. 在 GitHub 仓库 `Settings → Secrets and variables → Actions` 中添加：
   - Repository variable：`AMAP_JS_KEY`
   - Repository secret：`AMAP_SECURITY_CODE`
4. 合并到 `main` 后，由 GitHub Pages 工作流自动重新部署。

Key 和安全密钥不写入 Git 历史。浏览器端地图安全仍依赖高德控制台的域名白名单配置。
