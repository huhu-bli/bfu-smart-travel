# 北京科技大学学院路校园路线

本次新增学院路主校区的独立点位、数据库查询和校园路线能力，接在校园编辑一致性修复 PR #32 之后。未合并前，这些能力不代表正式站已经上线。

## 使用方式

可以问“北京科技大学校园逛两小时，从东门出发，想看图书馆和拍照”，再追问“改成一小时，换北门”。学校识别支持北京科技大学、北科大、北科、贝壳及大小写 USTB。景点数据库的范围选项增加北京科技大学；生成后可在全局计划增删、重新生成及刷新恢复，学校和数据来源保持不变。

主校区数据包含西门、南门、东门、北门、主楼、图书馆、校史馆、体育馆、银杏大道、运动场，共 10 个点位。默认从西门起步，用户可换门岗。地图沿用北京综合地图入口，同时提供官方校园地图链接，不复用北林 SVG 充当北科大地图。

## 数据边界

学校与地标名称参考以下学校公开资料，复核日期为 2026-11-01：

- [官方校园电子地图](https://map.ustb.edu.cn/)：区分本部与其他校区，检索主楼、图书馆、校史馆、体育馆。
- [官方校园平面图入口](https://gym.ustb.edu.cn/dtdh/xndt/index.htm)及[学校发布的平面图附件](https://srse.ustb.edu.cn/__local/8/25/CF/B2373EEC46A183F7F2CDF971259_A9E39B5B_2B2CD.pdf?e=.pdf)：用于确认校园入口、建筑和运动区域的名称。
- [学校迎新网校园地图说明](https://yx.ustb.edu.cn/szbk/xydt1.htm)和[学校电子地图上线报道](https://news.ustb.edu.cn/info/2514/68755.htm)：提及主楼及银杏大道景观。
- [学校校史馆介绍](https://oia.ustb.edu.cn/LifeUSTB/CampuCulture/USTBHistoryMuseum/index.htm)：用于校史展示内容的简短介绍。

点位的 x/y 坐标为项目示意布局，距离、步行时间和停留时间为产品估算，未做实地测绘，也没有从官方 GIS 导出道路网络。来源保留为 unverified，避免把名称核对误表述为坐标、开放时段和访客权限均已确认。开放时段、预约地址保持空值；路线默认场馆外围观察，进入室内前须按学校规定确认。

本批次不包含昌平、管庄、西三旗、顺德、雄安等其他校区或园区。明确要求未收录校区时返回不支持，不能替换为学院路主校区。

## 数据与部署

唯一资料源为 `database/catalogs/ustb-campus-2026-11-01.json`。`src/data/campuses/ustb.ts` 只把该文件投影为前端校园类型，避免维护两份不同的名称和介绍。

`006_ustb_campus.sql` 新增校园登记。`scripts/apply-campus-catalogs.mjs` 复用既有维护工具，在同一事务中登记批次校验值、地点、标签、来源和版本历史。`seedPlaces` 跳过该校园的旧静态种子写法，提交原始资料后调用校园批次；Vercel 生产发布在迁移后执行同一批次。已发布批次不能修改，后续资料变动应新增批次或使用维护工具。

本地运行 `npm ci`、`npm run db:setup`、`npm run dev:api`，另开终端运行 `npm run dev`。Preview 构建不写数据库，预览环境需使用自己的测试数据库并运行迁移与初始化。生产仍使用现有 Vercel 的 DATABASE_URL；仅部署 Pages 不会导入服务器上的北科大资料。

本次实现不直接写入线上数据库。未来合并并触发 Vercel 生产部署时，按现有构建命令导入批次。部署后应验证 `/api/places?scope=campus&campus_id=ustb&limit=100` 返回 source=database、total=10，并用真实千问执行一次校园路线。

## 回归测试

`api/ustbCampus.test.mjs` 通过 PGlite 实际 SQL 检查 10 个点位、门岗、别名、跨学校隔离、其他校区限制、助手追问、数据库编辑，以及旧数据库增量发布、重复导入和保留人工修改/归档状态。

内置助手的校园分支不再被学校全名中的“北京”关键字覆盖；学校全名的页面端请求与单元测试都覆盖此问题。未使用真实千问额度验证模型回复；真实服务依然依赖生产部署、模型额度和网络。

验收记录：7 项北科大专项测试通过，UTC 环境的完整测试为 135 项通过，类型检查、构建及差异空白检查通过。手机尺寸 390×844 的 Chrome 页面检查使用本地内存 SQL 数据库，并阻止真实千问请求：从完整学校名称生成路线、东门切换北门、图书馆移除后再加入、刷新恢复、官方地图链接及数据库筛选出 10 条记录均通过，未捕获页面运行错误。原有日期测试依赖时区，本次完整测试明确使用 UTC，与 GitHub Actions 的运行环境保持一致。
