# 海淀学校地图扩展

## 目标

在保留北京林业大学校园 SVG 精细地图和路线规划器的前提下，把项目的地图范围扩展到海淀区。第一阶段提供海淀学校总览，后续可以沿用相同数据层继续增加景点、科研院所、交通和餐饮。

## 为什么不把“所有学校”写进 `spots.ts`

`src/data/spots.ts` 描述的是北林校内可规划点位，字段和坐标都服务于校园步行算法。海淀学校数量更多、变化更频繁，而且需要真实经纬度。如果把两类数据混在一起：

- 校园路线算法会误把校外学校当成校内景点；
- 每次学校更名或新增都要重新修改代码；
- SVG 校园坐标与地理经纬度无法直接共用。

因此海淀学校使用地图服务运行时查询，并保持独立的数据配置和 UI 组件。

## 代码结构

```text
src/data/haidianSchools.ts   学校分类与检索任务
src/lib/amapLoader.ts        高德 JS API 加载与类型边界
src/components/HaidianMap.tsx 地图、筛选、搜索和学校列表
src/styles/haidian.css       海淀地图独立样式
```

`App.tsx` 只负责在“北林校园路线”和“海淀学校总览”之间切换，不改变现有规划器、Agent 或校园点位数据。

## 数据范围

页面会按高校、中学、小学和职业院校四类检索海淀区学校，并对结果去重。地图服务返回的 POI 不是教育部门名录，因此页面明确标注：它用于旅行和位置浏览，不承诺行政名录意义上的绝对全量。

如果后续需要正式全量名录，应把海淀区教育主管部门的公开数据导入独立后端或静态 JSON，再使用高德经纬度进行地理编码和校验。

## 部署配置

1. 在高德开放平台创建“Web 端（JS API）”应用和 Key。
2. 把 GitHub Pages 域名加入高德的安全域名白名单。
3. 在 GitHub 仓库 `Settings → Secrets and variables → Actions` 中添加：
   - Repository variable：`AMAP_JS_KEY`
   - Repository secret：`AMAP_SECURITY_CODE`
4. 重新运行 GitHub Pages 部署工作流。

高德 Key 不写入源代码。JS API Key 会随网页发送给浏览器，所以安全依赖域名白名单；安全密钥由 GitHub Actions 注入，不进入 Git 历史。

## 后续扩展

建议按以下顺序推进：

1. 接入正式学校名录并增加数据更新时间；
2. 给 Agent 增加 `search_haidian_schools` 工具；
3. 增加海淀景点、科研院所、地铁站等独立图层；
4. 在后端接入跨校交通时间，生成“高校参观路线”；
5. 对外部地图请求增加缓存和失败降级。
